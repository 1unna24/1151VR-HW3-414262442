# Unity 專案內容
本專案為 Unity 2D 輪盤遊戲，包含以下物件：
- Main Camera
- Roulette（2D 輪盤）
- Needle（指針）
- Pink Wallpaper（背景）
- RouletteController（輪盤控制程式）
- Audio Source（音效播放器）

# 製作流程與相關操作
## 1. Unity 專案建立
- 開啟 Unity Hub。
- 建立 2D 專案。
- 建立遊戲場景。
- 匯入輪盤、指針及背景素材。
## 2. Unity 場景配置
- 將輪盤圖片載入 Unity。
- 將指針放置於輪盤中央上方。
- 設定背景圖片及遊戲畫面。
- 調整各物件的位置與大小。
## 3. 輪盤旋轉功能製作
- 建立 `RouletteController.cs` 腳本。
- 使用滑鼠左鍵控制輪盤開始旋轉。
- 設定輪盤初始旋轉速度。
- 使用速度遞減的方式，讓輪盤逐漸減速停止。
## 4. 音效功能製作
- 使用 Audacity 剪輯輪盤音效。
- 調整音效音量及播放效果。
- 將音效匯入 Unity。
- 使用 Audio Source 播放輪盤音效。
- 透過程式控制音效播放及停止。
